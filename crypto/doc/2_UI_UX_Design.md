# 2. UI/UX 디자인 및 테마 (UI & UX Design)

## 2.1. 디자인 레퍼런스

- **TradingView 벤치마킹**: [트레이딩뷰 BTCUSD 차트](https://kr.tradingview.com/chart/?symbol=CRYPTO%3ABTCUSD)의 레이아웃과 프로페셔널한 디자인 요소를 기반으로 설계.
- **기본 레이아웃 구조**:
  - `상단 헤더(Header)`: 암호화폐 종목 검색, 시간대(Timeframe) 설정, 보조지표 메뉴, 다크/라이트 테마 전환 토글 버튼.
  - `좌측 툴바(Toolbar)`: 추세선, 피보나치 등 차트 그리기 커스텀 도구.
  - `중앙 메인 (Main Chart)`: 캔들스틱, 보조지표, 시그널 표시 구역.
  - `하단 및 우측 패널 (Panel)`: 자산 목록, 최근 거래 내역, 호가창 및 백테스팅 데이터 통계 UI.

## 2.2. 다크 모드 (기본) 및 라이트 모드 지원

웹 페이지의 기본 스타일은 트레이더들이 가장 선호하고 눈 피로가 덜한 다크 모드로 설정합니다.

- **다크 모드 (기본 테마)**:
  - 배경: 딥 네이비 혹은 다크 그레이 (`#131722` 계열).
  - 캔들: 상승(양봉) 뚜렷한 초록색 `#089981`, 하락(음봉) 뚜렷한 붉은색 `#f23645`.
  - 격자선 및 텍스트: 채도가 낮고 부드러운 회색 톤.
- **라이트 모드 (전환 가능)**:
  - 배경: 흰색 (`#FFFFFF`) 혹은 아주 밝은 회색 (`#f0f3f6`).
  - 시인성이 좋도록 캔들 테두리 및 텍스트 색상을 어두운(#131722 등) 색으로 자동 반전.
- **토글(Toggle) 시스템**:
  - CSS Variables(Custom Properties)를 사용하여 사용자 설정에 맞춰 전체 테마를 동적으로 On/Off 할 수 있는 기능 제공.
